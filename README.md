# python-mysql-automation

Automatización de tareas repetitivas con Python y MySQL. Ideal para negocios, tiendas y gestión de inventario.

### ¿Qué hace este proyecto?
- Conexión segura a base de datos MySQL (sin exponer contraseñas con archivo .env)
- Inserción, actualización y consulta automática de datos
- Registro de logs para control de errores
- Listo para conectar con Excel, formularios web y sistemas de inventario

### Tecnologías
Python, MySQL, mysql-connector, python-dotenv

### Caso de uso real
Este script es la base que uso para proyectos freelance de automatización de relleno de información, gestión de stock y migración de Excel a MySQL. Se adapta en 24h a cualquier cliente.

### Cómo usarlo
1. Clonar el repo
2. Crear archivo .env con credenciales MySQL
3. `pip install -r requirements.txt`
4. `python main.py`
